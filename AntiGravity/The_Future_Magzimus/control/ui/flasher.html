צריבה חוטית ראשונית (USB)

לצריבה ראשונית על מכשיר חדש (לפני שיש WiFi), חבר USB לחץ BOOT והרץ: 

# Staff S3
cd firmware/staff
pio run -e staff -t upload

# Staff C3
pio run -e staff-c3 -t upload

# Relay
cd firmware/relay && pio run -e relay -t upload

# PWM
cd firmware/pwm && pio run -e pwm -t upload

# Hub (ESP32 — לחץ BOOT ידנית)
cd firmware/hub && pio run -e hub-esp32 -t upload

לאחר הצריבה הראשונה — WiFi + OTA זמינים לכל העדכונים הבאים.
